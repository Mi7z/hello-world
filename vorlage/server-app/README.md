# Name der App

Was die App macht, in zwei bis drei Sätzen.

## Selbst betreiben

Hello World betreibt keine Server. Wer diese App nutzen will, betreibt sie selbst.

1. **Was du brauchst:** z. B. Node.js 20 oder neuer, einen Rechner oder Server.
2. **Herunterladen:** diesen Ordner kopieren.
3. **Einstellen:** `.env.beispiel` nach `.env` kopieren und ausfüllen (Schlüssel nie veröffentlichen).
4. **Starten:** `npm install && npm start`
5. **Aufrufen:** http://localhost:3000
6. **Aktualisieren:** neue Version holen, dann wieder starten.

## Kosten

Was der Betrieb grob kostet (zahlt der Betreiber).
