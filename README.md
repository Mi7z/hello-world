# Hello World

**Die offene Datenbank für Apps, Skills und KI-Werkzeuge.** Sag, was du brauchst. Gibt es die App schon, öffnet sie sich. Wenn nicht, baut deine eigene KI sie hier im Repository, geprüft und für alle verfügbar.

- **Browser-Apps** laufen direkt im Katalog, abgeschottet und ohne Internet. Deine Dateien bleiben auf deinem Gerät.
- **Server-Apps** sind erlaubt. Wer sie nutzen will, betreibt den Server selbst, mit Anleitung in jeder App.
- **Ähnliches gehört zusammen:** Neue Funktionen kommen bevorzugt in eine passende vorhandene App.
- **Skills und MCP-Werkzeuge für KIs:** Mit dem Plugin findet Claude, Codex & Co. sie selbstständig und nutzt sie. Siehe [INSTALLIEREN.md](INSTALLIEREN.md).
- **Jeder nutzt seine eigene KI.** Hello World selbst bleibt kostenlos.

## Herunterladen

Hello World gibt es als eigenes Programm für **Windows, Mac und Linux**:
[Neueste Version herunterladen](https://github.com/Mi7z/hello-world/releases/latest).
Öffnen, Wunsch eintippen – gibt es das Werkzeug schon, öffnet es sich, sonst
baut deine KI es. Als KI geht Claude auf deinem PC, ein eigener Schlüssel oder
**kostenlose KIs** (Gratis-Konten bei Gemini, OpenRouter, Groq, Cerebras, Mistral).

## Mitmachen

1. Repository klonen und deine KI darin arbeiten lassen (z. B. Claude Code). Die Regeln stehen in [AGENTS.md](AGENTS.md).
2. `node werkzeuge/pruefen.js` muss ohne Fehler laufen.
3. Pull Request stellen. Die Prüfung läuft auf GitHub automatisch.

Oder einfacher: Auf der Webseite den Wunsch eintippen, deine KI verbinden und bauen lassen.

## Lokal starten

```bash
node server.js   # http://localhost:8810
```
